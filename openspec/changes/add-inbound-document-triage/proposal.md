# Proposal: Inbound document triage

## Why
Bring case 003 into the OpenSpec delivery workshop without losing its business rules.

## What Changes
- Introduce the inbound-document-triage capability and its preserved source requirements.
- Supply a bounded JavaScript reference and executable examples.

## Scope of the teaching code
Deterministic routing of supplied classification results, exact-match corroboration, privacy holds, pause decisions and receipt clocks. No OCR/model, real attachments, persistent pause store, trained-reviewer authorization, reports or alerts delivery.

The specification describes the broader business intent; it is not a claim that the teaching code implements every rule. See [coverage](../../../workshop/coverage.json) for each requirement and scenario's disposition.

## Approval
