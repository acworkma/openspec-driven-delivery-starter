# 004 Vision-rider retrospective drill

Read only the [original epic](cases/004-vision-rider-retro/original-epic.md)
at first. Its gaps are intentional; do not improve the input before the drill.
Pair a product owner with a developer; ask an architect to challenge handoffs.

1. Read the epic and list questions before seeing code or clarified answers.
2. Draft an OpenSpec proposal and observable examples. Ask who approves,
   how dates and waiting periods work, what proves the administrator is ready,
   what happens to mid-year benefits and what stops a go-live.
3. Reveal the [clarified context](cases/004-vision-rider-retro/context.md)
   and [gap log](cases/004-vision-rider-retro/gap-log.md). Compare discoveries.
4. Inspect the [OpenSpec delta](../openspec/changes/add-vision-rider/specs/vision-rider/spec.md)
   and [Gherkin](../features/vision-retro.feature), then run
   `npx cucumber-js --tags @004` in the reference.
